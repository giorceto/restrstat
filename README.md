# restrstat — статистики от SAMO-Tour

Отделно Laravel приложение. Отваря се на **https://sales.tours-club.com/restrstat/**. Работи на същата машина като tc-sales,
но е с отделен код, отделна база, отделен потребител в Linux и отделен вход.

## Какво показва

| Страница | Съдържание |
|---|---|
| **Обзор** | оборот, марж, марж %, заявки, туристи, средна сума на заявка, средно нощувки и % анулирани; всичко се сравнява със същия период година по-рано, има и разбивка по месеци и топ дестинации |
| **Дестинации** | държава → курорт → хотел: заявки, туристи, нощувки, оборот, марж и промяна спрямо миналата година; таблицата се подрежда по всяка колона |
| **Време и сезон** | оборот по месец на продажба или на настаняване; кога се купува (дни преди тръгването); сезонът към днешна дата спрямо миналата година; натовареност — колко туристи са на почивка всяка седмица |
| **Анулации** | дял на анулираните по канал, по държава и по това колко време преди тръгването са анулирани |
| **Задължения към доставчици** | избира се фирма (по подразбиране само турските), период на продажба и период на настаняване; показва сумата на нетните цени, списък по заявки и експорт в CSV |

На всяка страница се филтрира по период (по дата на продажба или на настаняване) и по канал: нашите офиси, онлайн или външни агенции.

## Как работи

- `php artisan samo:sync` всеки час тегли от SAMO заявките, създадени или променени през последните 14 дни, заедно с
  услугите, доставчиците и местата. Веднъж седмично се тегли всичко. **SAMO само се чете.**
- Страниците четат само от нашата база (MariaDB). Към SAMO не се правят заявки на живо.
- **Без лични данни на клиенти.** Пазят се само номер на заявката, кой, за кого, дати, суми и **броят** туристи.
  Полето `claim.contact` (имейлът на клиента) не се чете.
- Сумите са в евро. Всяка услуга се превръща по своята валута: лв. ÷ 1,95583. В друга валута не се броят и страницата предупреждава.
- Маржът е продажна цена − нетна цена − комисиона на агенцията (`claim.commission` е процент).
- Дестинацията на заявката се взема от основната ѝ услуга, тоест хотела с най-висока цена.

## Команди

```
php artisan samo:check               # връзка, само четене ли е, колоните, които ползваме (✓/✗)
php artisan samo:check --find=hotel  # таблици и колони по част от името
php artisan samo:sync [--all]        # теглене (--all — всички заявки)
php artisan user:create имейл "Име"  # вход (паролата се пита)
php artisan demo load|clear          # измислени данни за проба / изчистване
php artisan test
```
